Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. Which of the following is a common web browser?

    Answer: Google Chrome

    Google Chrome is a web browser, while Word and Photoshop are productivity/creative apps, and Windows Explorer is a file manager.

  2. Which company developed the Android operating system before being acquired by Google?

    Answer: Android Inc.

    Android Inc. was founded in Palo Alto, California in 2003 by Andy Rubin, Rich Miner, Nick Sears, and Chris White. Google acquired the company in 2005 for approximately $50 million.

  3. What is the name of the button combination used to copy text or files?

    Answer: Ctrl + C

    Ctrl + C is the standard keyboard shortcut for 'Copy'. Ctrl + V is for Paste, and Ctrl + X is for Cut.

  4. What color is the 'Stop' button in most video player interfaces?

    Answer: Red

    The 'Stop' button is universally represented by the color red, while Play is usually green.

  5. What does the 'blue screen of death' (BSOD) usually indicate on a Windows computer?

    Answer: A system crash or critical error

    The Blue Screen of Death is a critical error screen displayed by Windows when the system encounters a fatal problem and crashes.

  6. Which of the following is a version control system used by developers?

    Answer: Git

    Git is a widely used distributed version control system for tracking changes in source code.

  7. Which of the following is considered a programming language?

    Answer: Python

    Python is a high-level programming language. HTML is a markup language, JPEG is an image format, and Wi-Fi is a wireless networking technology.

  8. In Git, which command uploads local repository commits to a remote repository?

    Answer: git push

    git push updates the remote branch with local commits.

  9. What is the term for a computer program that replicates itself by copying itself to other programs?

    Answer: Virus

    A computer virus is a type of malicious software that, when executed, replicates itself by modifying other computer programs and inserting its own code.

  10. Which of these is a type of malware that encrypts a victim's files and demands payment for decryption?

    Answer: Ransomware

    Ransomware is a type of malicious software that encrypts files on a victim's computer, demanding a ransom payment to restore access.

  11. In computing, what does 'open source' mean?

    Answer: Software whose source code is made publicly available

    Open source software has its source code publicly available, allowing anyone to view, modify, and distribute it under specific licenses.

  12. What is the time complexity of searching for an element in a balanced binary search tree with n nodes?

    Answer: O(log n)

    A balanced BST maintains a height of O(log n), so search runs in logarithmic time.

  13. In the context of programming, what is an 'API'?

    Answer: Application Programming Interface

    API (Application Programming Interface) is a set of rules and protocols that allows different software applications to communicate with each other, defining the methods and data formats that applications can use to request and exchange information.

  14. What does 'AI' stand for in modern technology?

    Answer: Artificial Intelligence

    AI stands for Artificial Intelligence, the simulation of human intelligence processes by computer systems, including learning, reasoning, and self-correction.

  15. Which API design style uses stateless communication and resource‑oriented URLs?

    Answer: REST

    RESTful APIs rely on stateless HTTP requests and resource‑based URLs to interact with services.
