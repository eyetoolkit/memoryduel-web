Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. Which of the following is a search engine?

    Answer: Google Search

    Google Search is a search engine. Firefox and Chrome are web browsers, while Adobe Acrobat is software used for reading and editing PDF files.

  2. What does the acronym 'HTTP' stand for in web addresses?

    Answer: HyperText Transfer Protocol

    HTTP (HyperText Transfer Protocol) is the foundation protocol for data communication on the World Wide Web, enabling the transfer of web pages between servers and browsers.

  3. What does 'www' stand for in a website URL?

    Answer: World Wide Web

    'www' stands for World Wide Web, the system of interlinked hypertext documents accessed via the internet.

  4. Who is known as one of the co-founders of Facebook?

    Answer: Mark Zuckerberg

    Mark Zuckerberg co-founded Facebook in his Harvard dorm room.

  5. What is used to connect a computer to the internet wirelessly?

    Answer: Wi-Fi

    Wi-Fi allows devices to connect to the internet wirelessly using radio waves, unlike wired Ethernet cables.

  6. What is the most common first step when you want to find information on the internet?

    Answer: Use a search engine

    Search engines like Google or Bing are the primary tools used to find information online.

  7. Which of these is the most common file extension for a web page?

    Answer: .html

    .html (HyperText Markup Language) is the standard extension for web pages, which browsers render to display content.

  8. Which of the following is a programming language commonly used for creating dynamic web content on the server side?

    Answer: Python

    Python is a versatile programming language often used for server-side web development (e.g., with frameworks like Django), unlike HTML/CSS which are markup/styling, or JPEG which is an image format.

  9. What is the primary role of a DNS (Domain Name System) server?

    Answer: To translate domain names into IP addresses

    DNS acts like a phonebook for the internet, translating human-readable domain names (like google.com) into machine-readable IP addresses.

  10. In the context of the internet, what does 'ISP' stand for?

    Answer: Internet Service Provider

    An Internet Service Provider (ISP) is a company that provides customers with access to the internet.

  11. What does 'HTTPS' indicate on a website address?

    Answer: The connection is encrypted and secure

    The 'S' in HTTPS stands for Secure, indicating that the communication between the browser and the website is encrypted using SSL/TLS.

  12. Which of the following is an example of 'Phishing'?

    Answer: An email pretending to be a bank to steal passwords

    Phishing is a type of social engineering where attackers send fraudulent communications (usually emails) that appear to come from a reputable source.

  13. What was the name of the first widely used graphical web browser that helped popularize the World Wide Web in the early 1990s?

    Answer: Mosaic

    NCSA Mosaic was the web browser that popularized the World Wide Web and the Internet, making it easy to view images and text together.

  14. Which of these is considered a foundational protocol of the modern internet, developed by Vint Cerf and Bob Kahn?

    Answer: TCP/IP

    TCP/IP (Transmission Control Protocol/Internet Protocol), developed by Vint Cerf and Bob Kahn in the 1970s, is the fundamental communication protocol suite that underpins the internet.

  15. Which protocol is primarily used to transfer hypertext files over the internet?

    Answer: HTTP

    HTTP (HyperText Transfer Protocol) is the foundation of data communication for the World Wide Web, specifically for transferring web pages.
