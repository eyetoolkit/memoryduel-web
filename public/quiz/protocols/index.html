Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What does the 'HTTP' in a web address stand for?

    Answer: HyperText Transfer Protocol

    HTTP is the foundational protocol used for transmitting hypermedia documents on the World Wide Web.

  2. Which protocol automatically assigns IP addresses to devices on a local network?

    Answer: DHCP

    DHCP (Dynamic Host Configuration Protocol) dynamically assigns IP addresses to devices on a local network.

  3. What does the 'www' at the beginning of many website addresses stand for?

    Answer: World Wide Web

    WWW stands for World Wide Web, the system of interconnected hypertext documents accessed via the internet.

  4. Which transport‑layer protocol provides reliable, ordered delivery of data?

    Answer: TCP

    TCP (Transmission Control Protocol) ensures data arrives intact and in the correct sequence through acknowledgments and retransmission.

  5. What is the primary difference between TCP and UDP protocols?

    Answer: TCP provides guaranteed delivery, UDP does not

    TCP ensures reliable, ordered delivery of data, while UDP provides faster but unreliable transmission.

  6. What does 'DNS' stand for in networking?

    Answer: Domain Name Server

    DNS (Domain Name System) is the phonebook of the internet, translating human-readable domain names (like example.com) into IP addresses.

  7. Which protocol is used for secure communication over the internet?

    Answer: HTTPS

    HTTPS (HTTP Secure) uses SSL/TLS encryption to secure communication between a web browser and a website.

  8. In IPv4 addressing, what is the maximum decimal value that any octet can have?

    Answer: 255

    Each octet in an IPv4 address ranges from 0 to 255.

  9. What is the primary function of a DNS (Domain Name System) server?

    Answer: Translating domain names into IP addresses

    DNS acts like a phonebook for the internet, converting human-readable domain names (like example.com) into IP addresses computers use to connect.

  10. Which protocol is used to securely browse websites, indicated by 'https'?

    Answer: TLS/SSL

    HTTPS uses TLS/SSL encryption to secure communication between a browser and a website.

  11. In IPv6, how many bits long is an address?

    Answer: 128 bits

    IPv6 addresses are 128 bits long, allowing a vastly larger address space.

  12. What is the key advantage of IPv6 over IPv4?

    Answer: It provides a vastly larger address space

    IPv6 uses 128-bit addresses compared to IPv4's 32-bit addresses, solving the address exhaustion problem for the growing number of internet-connected devices.

  13. In the OSI model, which layer is responsible for routing data packets between different networks?

    Answer: Layer 3 (Network)

    The Network Layer (Layer 3) of the OSI model handles logical addressing (like IP addresses) and determines the path data packets take across networks through routers.

  14. Which of these is considered a foundational protocol suite that underpins the modern internet?

    Answer: TCP/IP

    TCP/IP (Transmission Control Protocol/Internet Protocol) is the fundamental communication protocol suite that enables the internet to function.

  15. In what year was TCP/IP adopted as the standard protocol for ARPANET, marking the foundation of the modern Internet?

    Answer: 1983

    TCP/IP was officially adopted as the standard protocol for ARPANET on January 1, 1983, a date known as 'flag day.' This standardized communication allowed different computer networks to interconnect, forming the basis of today's Internet.
