Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What is the name of the process by which a computer converts data into a format that is unreadable without the proper decryption key?

    Answer: Encryption

    Encryption is the process of converting data into a coded format to prevent unauthorized access. It can only be decrypted with the correct key.

  2. What type of cyberattack involves sending deceptive emails that appear to come from a trusted source to trick victims into revealing sensitive information?

    Answer: Phishing

    Phishing relies on social engineering, using convincing messages to lure users into disclosing passwords, credit‑card numbers, etc.

  3. Which of the following is a common type of malware that encrypts a victim's files and demands payment for decryption?

    Answer: Ransomware

    Ransomware is a malicious software that locks users out of their files or systems by encrypting them, demanding a ransom payment to restore access.

  4. What is the term for malicious software designed to extort money, typically by encrypting files?

    Answer: Ransomware

    Ransomware is a type of malicious software that encrypts a victim's files and demands payment (ransom) for the decryption key.

  5. Which of these is an example of 'phishing'?

    Answer: An email pretending to be from a bank asking for your password

    Phishing is a cyber attack where attackers send fraudulent communications that appear to come from a reputable source to steal sensitive data.

  6. What is the purpose of a firewall in cybersecurity?

    Answer: To monitor and control incoming and outgoing network traffic

    A firewall acts as a barrier between a trusted internal network and untrusted external networks (like the internet), monitoring traffic based on security rules.

  7. What is the primary purpose of a VPN (Virtual Private Network)?

    Answer: To provide a secure, encrypted connection over a public network

    A VPN creates a private, encrypted tunnel for data over a public network like the internet, helping to protect online activity from eavesdropping and enhance user privacy.

  8. Which technique is used to prevent replay attacks in authentication protocols?

    Answer: Timestamps or nonces

    Using a nonce or timestamp ensures that a captured authentication message cannot be reused.

  9. Which protocol secures data transmission over the web using asymmetric encryption to establish a session?

    Answer: TLS

    TLS (Transport Layer Security) uses public‑key cryptography to encrypt and authenticate web communications.

  10. In what year was the first computer virus, called 'Creeper', detected on ARPANET?

    Answer: 1971

    Creeper was detected in 1971 on ARPANET (the precursor to the internet). It was created by BBN Technologies engineer Bob Thomas and is considered one of the first computer worms.

  11. What cryptographic principle does a hash function like SHA‑256 exhibit?

    Answer: One-way function

    SHA‑256 is designed to be a one‑way function, making it computationally infeasible to reverse the hash to obtain the original input.

  12. Which algorithm is commonly used for public-key encryption in SSL/TLS?

    Answer: RSA

    RSA is widely used for public-key encryption in SSL/TLS to secure key exchange.

  13. Which emerging technology uses quantum entanglement to enable secure communication over long distances?

    Answer: Quantum Key Distribution

    Quantum Key Distribution (QKD) leverages quantum entanglement to distribute encryption keys with theoretical security against eavesdropping.

  14. What was the name of the first major computer virus that spread via email?

    Answer: Melissa

    The Melissa virus, released in 1999, was one of the first macro viruses to spread rapidly via email. It masqueraded as a list of passwords and automatically sent copies to the first 50 contacts in the recipient's email address book.

  15. Which key‑exchange method is no longer supported in TLS 1.3?

    Answer: RSA key transport

    TLS 1.3 removed static RSA key transport, leaving only (EC)DH‑based exchanges.
