Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. Which company developed the iPhone?

    Answer: Apple

    Apple Inc. introduced the first iPhone in 2007, revolutionizing the smartphone industry.

  2. Which company created the Android operating system for smartphones?

    Answer: Google

    Android was developed by Android Inc., which was founded in 2003 and later acquired by Google in 2005.

  3. Which of these is considered the 'father' of the World Wide Web?

    Answer: Tim Berners-Lee

    Sir Tim Berners-Lee invented the World Wide Web in 1989 while working at CERN, creating the first web browser and web server.

  4. Which of these is a common example of 'phishing'?

    Answer: An email pretending to be from a bank asking for your password

    Phishing is a cyberattack where scammers send fraudulent messages (often emails) pretending to be from reputable organizations to trick people into revealing sensitive information like passwords or credit card numbers.

  5. What is the name of the physical connector used to charge most modern Android smartphones?

    Answer: USB Type-C

    USB Type-C has become the industry standard connector for transmitting data and power in many modern devices.

  6. What is the name of the first commercially available graphical web browser?

    Answer: Mosaic

    Mosaic, released in 1993, was the first web browser to display images inline with text, making it the first widely popular graphical browser and sparking the growth of the World Wide Web.

  7. Which programming language, created by Guido van Rossum, is known for its readability and is often recommended for beginners?

    Answer: Python

    Python was created by Guido van Rossum and first released in 1991. It emphasizes code readability with its use of significant indentation.

  8. Which programming language is primarily used for styling web pages?

    Answer: CSS

    Cascading Style Sheets (CSS) is the language used for describing the presentation of a document written in HTML or XML, including colors, layout, and fonts.

  9. Which generation of mobile networks introduced the ability to stream video reliably on smartphones?

    Answer: 4G

    4G networks, which became widespread around 2010, provided the bandwidth and speed necessary for reliable mobile video streaming and similar data-intensive applications.

  10. Which of these is a characteristic of 'cloud computing'?

    Answer: Resources are provided over the internet on-demand

    Cloud computing involves delivering computing services (servers, storage, databases) over the internet ('the cloud').

  11. Which technology underlies cryptocurrencies and provides a distributed ledger?

    Answer: Blockchain

    Blockchain is a decentralized, immutable ledger used by cryptocurrencies.

  12. What is the term for the massive, decentralized network of computers that makes up the Bitcoin system?

    Answer: Blockchain

    Blockchain is a distributed ledger technology that records transactions across many computers so that the record cannot be altered retroactively.

  13. Which consensus algorithm is used by the Bitcoin network to validate transactions and secure the blockchain?

    Answer: Proof of Work (PoW)

    Bitcoin uses Proof of Work (PoW), where miners compete to solve complex mathematical puzzles to validate transactions and add new blocks to the blockchain.

  14. What technology allows multiple users to share the same hardware resources simultaneously through virtualization?

    Answer: Virtualization

    Virtualization creates a virtual version of something (like an operating system or server) allowing multiple instances to run on the same physical hardware.

  15. Who is often referred to as the 'father of computer science' for his theoretical work on computing machines and algorithms?

    Answer: Alan Turing

    Alan Turing is widely considered the father of theoretical computer science and artificial intelligence, formalizing the concepts of algorithm and computation with the Turing machine.
