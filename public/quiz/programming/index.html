Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What is the term for a set of instructions that a computer's processor can execute directly without translation?

    Answer: Machine code

    Machine code consists of binary instructions the CPU can run directly.

  2. What does 'HTML' stand for in web development?

    Answer: HyperText Markup Language

    HTML (HyperText Markup Language) is the standard markup language used to create web pages and structures content on the internet.

  3. What does "HTML" stand for?

    Answer: HyperText Markup Language

    HTML is the standard markup language for creating web pages and web applications.

  4. Which of these is primarily used to convert binary code (0s and 1s) into the text you see on screen?

    Answer: Compiler/Interpreter

    Both compilers and interpreters translate source code into machine-executable instructions or intermediate forms for display.

  5. Which of the following is a widely used markup language for creating web pages?

    Answer: HTML

    HTML (HyperText Markup Language) is the standard language used to structure content on the web.

  6. Which programming paradigm treats a program as a set of objects that contain data and methods?

    Answer: Object‑oriented programming

    Object‑oriented programming models real‑world entities as objects that bundle state and behavior.

  7. Which of the following is NOT a programming language?

    Answer: HTML

    HTML (HyperText Markup Language) is a markup language used to structure content on the web, not a programming language used for logic and algorithms.

  8. Which programming paradigm treats functions as first‑class objects, enabling higher‑order functions and pure computations?

    Answer: Functional

    Functional programming emphasizes immutability and first‑class functions, allowing functions to be passed as arguments and returned.

  9. Which of these is NOT an operating system?

    Answer: Python

    Python is a programming language, not an operating system. Linux, Windows, and macOS are all operating systems.

  10. Which of the following is a programming language?

    Answer: Python

    Python is a popular programming language used for web development, data science, and automation. HTML is a markup language, and Ethernet and JPEG are not languages.

  11. Which of the following programming languages was specifically designed for scientific and numerical computing by John McCarthy and others at MIT?

    Answer: LISP

    LISP (List Processing), created by John McCarthy at MIT in 1958, was one of the earliest high-level programming languages and was influential in artificial intelligence research. FORTRAN was designed for numerical computation by IBM, COBOL for business, and BASIC for education.

  12. In computing, what does the acronym 'SQL' stand for?

    Answer: Structured Query Language

    SQL (Structured Query Language) is the standard programming language specifically designed for managing data held in a relational database management system.

  13. What is the hexadecimal color code for pure white?

    Answer: #FFFFFF

    In hex color codes, FFFFFF represents the maximum intensity of Red, Green, and Blue, resulting in white. 000000 is black.

  14. Which of these is the hexadecimal representation of decimal number 255?

    Answer: FF

    In hexadecimal, 15 is represented as F. Since 255 = 16 * 15 + 15, it is represented as FF.

  15. Which of these programming languages was created by Brendan Eich?

    Answer: JavaScript

    Brendan Eich created JavaScript in 1995 while working at Netscape. Python was created by Guido van Rossum, Java by James Gosling, and C++ by Bjarne Stroustrup.
