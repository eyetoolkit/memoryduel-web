Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What is the primary function of a firewall?

    Answer: Filter network traffic based on rules

    Firewalls monitor and control incoming and outgoing traffic according to predefined security rules.

  2. What is the main purpose of a firewall?

    Answer: To block unauthorized network traffic

    Firewalls monitor and control incoming/outgoing traffic, blocking unauthorized access.

  3. Which of these is a type of computer virus?

    Answer: Worm

    A worm is a standalone malware computer program that replicates itself in order to spread to other computers.

  4. Which of these is a common example of 'phishing'?

    Answer: An email pretending to be from a bank asking for your password

    Phishing is a cyberattack where scammers send fraudulent messages (often emails) pretending to be from reputable organizations to trick people into revealing sensitive information like passwords or credit card numbers.

  5. What is the common term for a malicious software program that damages computers?

    Answer: Virus

    A computer virus is a type of malicious software that, when executed, replicates itself by modifying other computer programs and inserting its own code.

  6. Which of the following is the most common protocol used to secure web browsing (indicated by a padlock icon in the browser)?

    Answer: HTTPS

    HTTPS (HTTP Secure) encrypts communication between a web browser and a server, providing security and privacy.

  7. What is the term for a computer program that replicates itself and spreads to other computers, often causing harm?

    Answer: Virus

    A computer virus is a malicious program that spreads by attaching itself to files or programs and replicating.

  8. Which protocol is primarily used to securely transfer data over the internet, indicated by 'https://'?

    Answer: TLS/SSL

    HTTPS uses TLS (Transport Layer Security) or its predecessor SSL to encrypt communication between a browser and a server.

  9. Which technique uses a fixed‑size hash value to verify the integrity of data?

    Answer: Hashing

    Hashing generates a deterministic, fixed‑size digest that can detect any alteration of the original data.

  10. What is a 'firewall' in computer security?

    Answer: A system that monitors and controls network traffic

    A firewall monitors incoming and outgoing network traffic and blocks unauthorized access based on security rules.

  11. What does the 'H' in 'HTTPS' stand for?

    Answer: HyperText

    HTTPS stands for HyperText Transfer Protocol Secure. The 'S' indicates that the communication between the user's browser and the website is encrypted using SSL/TLS.

  12. Which of these best describes 'phishing'?

    Answer: A social engineering attack to steal credentials

    Phishing is a social engineering attack where attackers impersonate trusted entities to trick users into revealing sensitive information.

  13. What does the 'O' in 'OAuth' stand for?

    Answer: Open

    OAuth (Open Authorization) is an open standard for access delegation, commonly used as a way for internet users to grant websites or applications access to their information on other websites without giving away their passwords.

  14. Which encryption standard is commonly used for securing Wi-Fi networks (WPA2)?

    Answer: AES

    WPA2 uses AES (Advanced Encryption Standard) to secure wireless network traffic.

  15. Which of the following is considered a 'dark web' feature?

    Answer: It requires special software like Tor for access

    The dark web is a part of the internet that requires special software, such as Tor, to access and is designed to anonymize user activity.
