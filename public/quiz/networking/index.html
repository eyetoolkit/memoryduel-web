Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What does the 'Wi' in Wi-Fi stand for?

    Answer: It doesn't stand for anything; it's just a brand name.

    Despite popular belief, 'Wi-Fi' is not an abbreviation for 'Wireless Fidelity'. It is a marketing name created by the Wi-Fi Alliance, similar to how 'Kodak' or 'Google' are brand names.

  2. What is the main purpose of a firewall?

    Answer: To block unauthorized network traffic

    Firewalls monitor and control incoming/outgoing traffic, blocking unauthorized access.

  3. What does MAC address stand for?

    Answer: Media Access Control address

    MAC address is the abbreviation for Media Access Control address, a unique identifier assigned to network interfaces.

  4. What does the term 'Wi-Fi' commonly refer to?

    Answer: A wireless networking technology

    Wi-Fi is a wireless networking technology that allows devices like computers, smartphones, and IoT gadgets to connect to the internet or communicate with each other wirelessly.

  5. Which device is commonly used to connect multiple computers in a local area network (LAN)?

    Answer: Switch

    A switch operates at Layer 2 and forwards frames based on MAC addresses to connect devices within a LAN.

  6. What is a 'server' in computing?

    Answer: A computer that provides data to other computers

    Servers provide services or resources to other computers, known as clients.

  7. What does an IP address identify on a network?

    Answer: A specific device or computer

    An IP (Internet Protocol) address is a unique numerical label assigned to each device connected to a computer network.

  8. In computing, what is an 'IP address' primarily used for?

    Answer: To identify a device on a network

    An Internet Protocol (IP) address serves as a unique identifier for a device connected to a computer network.

  9. Which version of the HTTP protocol introduced header compression and multiplexing?

    Answer: C) HTTP/2

    HTTP/2 added header compression and multiplexed streams over a single TCP connection.

  10. What is the primary purpose of a DNS server?

    Answer: Translate domain names to IP addresses

    DNS resolves human‑readable domain names into the numeric IP addresses needed for routing.

  11. In IPv6, how many bits does an address contain compared to IPv4's 32‑bit address?

    Answer: 128‑bit

    IPv6 uses 128‑bit addresses to accommodate the vastly larger address space.

  12. What does 'TCP' stand for in the TCP/IP protocol suite?

    Answer: Transmission Control Protocol

    TCP (Transmission Control Protocol) is one of the main protocols of the Internet protocol suite, responsible for reliable, ordered delivery of data.

  13. What is the primary advantage of IPv6 over IPv4?

    Answer: It supports a vastly larger number of unique IP addresses

    IPv4 uses 32-bit addresses (about 4.3 billion), while IPv6 uses 128-bit addresses (about 340 undecillion), solving the address exhaustion problem.

  14. In IPv6, what is the length of the interface identifier in a link-local address generated using the EUI-64 method?

    Answer: 64 bits

    IPv6 link-local addresses use a 64‑bit prefix and a 64‑bit interface identifier created via EUI‑64.

  15. In the OSI model of computer networking, which layer is responsible for end-to-end communication and error recovery?

    Answer: Transport Layer

    The Transport Layer (Layer 4) in the OSI model handles end-to-end communication, flow control, and error recovery (e.g., TCP).
