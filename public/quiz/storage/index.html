Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. Which of these is a common computer storage unit larger than a gigabyte?

    Answer: Terabyte

    A terabyte (TB) is 1,024 gigabytes, making it larger than a gigabyte, megabyte, or byte.

  2. What does the acronym 'SSD' stand for in computer hardware terminology?

    Answer: Solid State Drive

    An SSD (Solid State Drive) is a type of storage device that uses integrated circuit assemblies to store data persistently, using flash memory. Unlike traditional hard disk drives (HDDs), SSDs have no moving mechanical components.

  3. Which of the following is a common solid‑state storage technology used in modern laptops?

    Answer: SSD

    Solid‑state drives (SSDs) use flash memory and have no moving parts, making them faster and more durable than HDDs.

  4. What does the 'GB' in storage sizes stand for?

    Answer: Gigabyte

    GB stands for Gigabyte, a unit of digital information storage. One gigabyte equals approximately one billion bytes.

  5. What does "SSD" stand for?

    Answer: Solid State Drive

    An SSD is a storage device that uses flash memory to provide faster read/write speeds than traditional hard drives.

  6. Which of these is a common type of storage device used to permanently store data?

    Answer: Hard Drive (HDD/SSD)

    Hard drives (HDDs and SSDs) are used for permanent storage. RAM is temporary memory, while CPUs and GPUs are processing units.

  7. Which of the following is a non-volatile storage technology that uses flash memory?

    Answer: SSD

    Solid State Drives (SSDs) use NAND flash memory and retain data without power.

  8. Which RAID level combines striping and mirroring to improve performance while providing redundancy?

    Answer: RAID 10

    RAID 10 (1+0) uses both mirroring (RAID 1) and striping (RAID 0) for speed and fault tolerance.

  9. Which type of storage device is most resistant to physical shock because it has no moving parts?

    Answer: SSD (Solid State Drive)

    SSDs use flash memory chips rather than spinning magnetic platters, making them more durable and faster than traditional HDDs.

  10. Which of the following is a type of computer memory that retains data even when powered off?

    Answer: ROM

    ROM (Read-Only Memory) is non-volatile memory that retains its contents even without power, often used to store firmware like the BIOS.

  11. Which technique is used in RAID 5 to distribute parity information across drives?

    Answer: Striping with parity

    RAID 5 stripes data blocks and distributes parity blocks, allowing recovery from a single drive failure.

  12. What is the primary advantage of using an SSD (Solid State Drive) over a traditional HDD (Hard Disk Drive)?

    Answer: SSDs are significantly faster because they have no moving parts

    SSDs use flash memory with no moving mechanical parts, making them much faster than HDDs which rely on spinning disks and moving read/write heads, though SSDs are typically more expensive per gigabyte.

  13. Which RAID level provides dual parity to tolerate up to two simultaneous disk failures while using block‑level striping?

    Answer: RAID 6

    RAID 6 uses dual parity to tolerate two simultaneous disk failures while striping data at the block level.

  14. Which of these is a type of non-volatile memory that is faster than a traditional hard drive but slower than RAM?

    Answer: NAND Flash (SSD)

    NAND Flash (used in SSDs) is non-volatile (retains data without power) and offers speeds between volatile RAM and mechanical HDDs.

  15. Which component of an SSD's controller performs wear‑leveling to extend the drive's lifespan?

    Answer: Flash Translation Layer (FTL)

    The Flash Translation Layer (FTL) in an SSD performs wear‑leveling and maps logical addresses to physical NAND pages.
