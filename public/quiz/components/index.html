Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What does 'RAM' stand for in computing?

    Answer: Random Access Memory

    RAM (Random Access Memory) is a form of computer memory that can be accessed randomly and is used to store data that is being actively used.

  2. What is 'RAM' primarily used for in a computer?

    Answer: Temporary data storage for running programs

    RAM (Random Access Memory) is volatile memory used to store data that the computer is currently using, allowing for fast access by the CPU.

  3. Which component is considered the 'brain' of a computer?

    Answer: CPU

    The Central Processing Unit (CPU) carries out instructions and processes data, making it the brain of the computer.

  4. What is the main function of a CPU (Central Processing Unit) in a computer?

    Answer: Executing instructions and performing calculations

    The CPU is often called the 'brain' of the computer because it carries out arithmetic, logic, controlling, and input/output operations specified by the instructions in the program.

  5. In the board game "Carcassonne," what is the term for the small wooden tokens players place to claim roads, cities, and fields?

    Answer: Meeples

    Meeples, a portmanteau of 'my people,' are the distinctive wooden player tokens used in Carcassonne and many other modern board games.

  6. What is the main purpose of RAM (Random Access Memory)?

    Answer: To hold data temporarily for the CPU to use quickly

    RAM is a form of computer memory that can be read and changed in any order, typically used to store working data and machine code currently in use.

  7. Which of the following is considered a 'peripheral' device?

    Answer: Monitor

    A peripheral is a device connected to a computer to input or output information, such as a monitor, keyboard, or printer, as opposed to the core internal components like the CPU or motherboard.

  8. Which of these is NOT a type of computer memory?

    Answer: SSD

    SSD (Solid-State Drive) is a type of storage device used for long-term data retention, while RAM (Random Access Memory), ROM (Read-Only Memory), and Cache are types of volatile or non-volatile memory used for temporary data and instructions.

  9. Which type of storage device has no moving parts and is generally faster and more durable than a traditional hard drive?

    Answer: SSD (Solid State Drive)

    SSDs use flash memory to store data, having no moving mechanical parts. This makes them faster, more resistant to physical shock, and generally more reliable than traditional HDDs.

  10. What does 'SSD' stand for in the context of computer storage?

    Answer: Solid State Drive

    An SSD (Solid State Drive) uses flash memory to store data, offering faster speeds and better durability than traditional HDDs (Hard Disk Drives).

  11. What is the name of the main circuit board in a computer?

    Answer: Motherboard

    The motherboard is the main printed circuit board (PCB) that houses the central processing unit (CPU) and connects all other components.

  12. What is the primary purpose of the 'Motherboard' in a computer?

    Answer: To connect and communicate between all components

    The motherboard is the main printed circuit board (PCB) that houses the CPU, memory, connectors for input/output devices, and other essential components, allowing them to communicate with each other.

  13. What is the main advantage of a Solid State Drive (SSD) over a traditional Hard Disk Drive (HDD)?

    Answer: Faster read/write speeds and durability

    SSDs use flash memory with no moving parts, offering significantly faster data access and greater physical durability compared to mechanical HDDs, though often at a higher cost per GB.

  14. What is the primary function of a GPU?

    Answer: Rendering graphics and images

    A GPU (Graphics Processing Unit) is specialized for parallel processing and is primarily used for rendering images, video, and 3D graphics.

  15. What is the 'motherboard' of a computer?

    Answer: The main circuit board that connects all components together

    The motherboard is the main printed circuit board (PCB) in a computer. It holds and allows communication between many of the crucial electronic components of the system, such as the CPU and memory, and provides connectors for other peripherals.
