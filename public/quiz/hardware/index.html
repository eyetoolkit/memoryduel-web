Answer key

All fifteen questions above, with the correct answer and the reasoning.

  1. What is the name of the device that forwards data packets between different computer networks?

    Answer: Router

    A router forwards data packets between distinct networks, directing traffic based on IP addresses.

  2. What type of device is a 'mouse' in computing?

    Answer: Input device

    A computer mouse is an input device used to point at and select items on a screen.

  3. Which component of a computer is responsible for rendering visual output to a display?

    Answer: GPU

    The GPU (Graphics Processing Unit) renders images and video for display.

  4. Which component is often referred to as the 'brain' of a computer?

    Answer: CPU (Central Processing Unit)

    The CPU (Central Processing Unit) executes instructions and performs calculations, acting as the main processor or 'brain'.

  5. What does 'CPU' stand for in a computer?

    Answer: Central Processing Unit

    CPU stands for Central Processing Unit, often referred to as the 'brain' of the computer.

  6. Which component of a CPU performs arithmetic operations such as addition and multiplication?

    Answer: Arithmetic Logic Unit (ALU)

    The ALU performs arithmetic and logical operations in a CPU.

  7. Which type of storage is faster because it has no moving parts?

    Answer: SSD

    SSDs (Solid State Drives) use flash memory with no moving parts, making them faster than traditional HDDs.

  8. Which type of storage is non-volatile, meaning it retains data even without power?

    Answer: SSD

    SSDs (Solid State Drives) are non-volatile storage devices. RAM and caches are volatile and lose data when power is removed.

  9. Which company manufactures the Snapdragon series of processors?

    Answer: Qualcomm

    Qualcomm's Snapdragon processors are widely used in smartphones and other mobile devices.

  10. What is the name of the technology that allows a single USB port to be used for charging and data transfer, often found on modern smartphones?

    Answer: USB-C

    USB-C is a modern connector standard that supports high data transfer rates and power delivery (charging) in a single, reversible plug.

  11. Which technology allows wireless communication over short distances, commonly used for connecting headphones or keyboards?

    Answer: Bluetooth

    Bluetooth is a wireless technology standard for exchanging data over short distances, ideal for personal area networks.

  12. Which company produced the first commercial microprocessor, the Intel 4004, in 1971?

    Answer: Intel

    The Intel 4004 is widely considered the first commercially available microprocessor, marking a major milestone in computing history.

  13. What does 'Moore's Law' refer to in computing?

    Answer: Transistor count on chips roughly doubling every two years

    Moore's Law, proposed by Gordon Moore in 1965, states that the number of transistors on a microchip doubles approximately every two years, driving computing power growth.

  14. Which quantum computing concept describes the ability of qubits to exist in multiple states simultaneously?

    Answer: Superposition

    Superposition allows a qubit to represent both 0 and 1 at the same time, enabling quantum parallelism.

  15. What was the name of the first general-purpose electronic digital computer, completed in 1945?

    Answer: ENIAC

    ENIAC (Electronic Numerical Integrator and Computer) was completed in 1945 and is widely considered the first general-purpose electronic digital computer.
